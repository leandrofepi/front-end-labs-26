Sumário dos projetos

1) cards/
- Descrição: Demonstração de cartões de planos (Gratuito, Profissional, Elite) com estilo e interações CSS.
- Arquivos principais:
  - cards/index.html
  - cards/style.css
- Destaques: uso de variáveis CSS (:root), fontes do Google (Poppins), ícones Material Symbols e transições de hover.

2) forms/
- Descrição: Conjunto de exemplos de formulários HTML5 com validações nativas e layouts em grid/flex.
- Arquivos principais:
  - forms/form-cadastro.html — formulário de cadastro com fieldsets (Dados Pessoais, Endereço, Login) e validações de CPF/CEP, minlength, type=email.
  - forms/form-fale-conosco-flex.html — formulário ‘Fale Conosco’ com layout flex e encaminhamento para send-message.html.
  - forms/send-message.html — página de confirmação.
  - pasta forms/css/ — estilos (reset e específicos).
- Destaques: boas práticas de marcação (labels, placeholders, atributos required/pattern) e exemplos de upload de avatar.

3) html-basico/
- Descrição: Mini-site temático “Mirror Fashion” usado para exercícios de design system e componentes estáticos.
- Arquivos principais:
  - html-basico/index.html
  - html-basico/about-us.html
  - pasta html-basico/css/ (reset.css, design-system.css, components.css, style.css)
  - pasta html-basico/img/ (imagens usadas no layout)
- Destaques: organização por componentes (classes com prefixo c-), cards informativos, hero, header fixo e footer.

Como visualizar os projetos
- Estes são sites puramente estáticos. Para ver localmente, basta abrir o arquivo HTML correspondente no navegador (duplo clique) ou servir a pasta com um servidor estático (ex.: extensão Live Server do VS Code ou utilitários como http-server / serve).
